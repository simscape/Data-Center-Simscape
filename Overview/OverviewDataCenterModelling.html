A data center acts as a coupled thermal and electrical load on the power grid and the cooling infrastructure facilities. This project provides a scalable framework to model data center hierarchies from the individual processor chip up to the IT tray, server racks, power distribution units (PDUs), and cooling distribution units (CDUs). To view the complete library of custom and composite blocks, open the Simulink Library Browser to view the Simscape Custom Components / Datacenter components.

Model Architecture

The data center model is structured hierarchically to replicate physical installations:
  • Server Chips: The fundamental source of heat generation and electrical power consumption.
  • IT Trays: Modules containing arrays of server chips, modeled as lumped thermal masses. Trays can optionally incorporate a cold plate for liquid cooling applications.
  • Server Racks and PDUs: Stacks of IT trays integrated with power distribution and local thermal management.
  • CDUs and Fan Units: System-level assemblies that manage heat rejection for multiple racks.

Component Modeling

Server Chip

The Server Chip block (found under Simscape Custom Components / Datacenter / PDU) estimates the power consumption and thermal dissipation at the chip level. The block parameters accept name-plate values for average power consumption. It calculates active electrical power requirements and the thermal responses using an empirical equation (for mathematical details, refer to DocumentationServerChip.html). This block can represent individual CPUs or GPUs.

Server Tray

The Server Tray composite block models an array of chips and their associated thermal network on a single IT tray. The electronics and structural tray are represented as a lumped thermal mass that absorbs heat from all onboard components. For liquid-cooled architectures, the Server Tray (TL) composite block integrates the standard Server Tray with a Cold Plate block to model the thermal interface between the lumped mass and the liquid coolant loop.

PDU Rack and Assemblies

Multiple IT Tray blocks are combined with flow and thermal multiplier blocks to construct a PDU Rack block. To simplify computational complexity, the framework applies the following modeling assumptions:
  • All server chips within a single Server Tray or PDU Rack block operate under a uniform utilization factor.
  • Flow and thermal multiplier blocks scale the aggregate mass flow rates and thermal domains.
For large-scale facility modeling, select pre-configured blocks from the Assemblies sub-library. These blocks utilize the scaling multipliers to connect PDU racks with system-level CDUs or air-cooling units, representing high-capacity data center sectors while maintaining simulation efficiency.
