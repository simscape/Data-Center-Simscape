Overview

In this project, you will find eight different workflows that help you in designing the data centers using Simscape. You start by building and parameterizing liquid-cooled or air-cooled data center plant models using the composite library blocks provided in this project. On the thermal side, you size the cooling system over a full year of local weather, tune control settings to achieve a low PUE, design the chiller, cooling tower, and pump temperature controller, and evaluate aisle and server temperatures for air-cooled layouts. On the electrical side, you design a double-conversion UPS validated against IEC 62040-3 and ITIC, evaluate a Solid State Transformer with CHB-DAB power delivery to GPU racks, and assess MW-scale network stability under firmware faults, weak grids, and UPS degradation.

Get Started

Double-click on the DataCenterDesignSimscape PRJ file (in the root folder) to setup the project and get started.
